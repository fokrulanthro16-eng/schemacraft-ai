## 🎙️ Verbatim Voice-Over Script

### Slide 1: The Bottleneck & The Solution (0:00 - 0:24)
> **Visual:** Screen opens on SchemaCraft Studio header and the initial 3NF relational cards (`01_hero_and_erd.png`).
> 
> **Voice-Over (Verbatim):**  
> *"Every software engineer and hackathon team knows the friction: before you can write a single line of frontend code or business logic, you lose four to eight hours designing relational tables, fighting foreign key migrations, writing Prisma schemas, and fabricating fake JSON mock data.*
> 
> *Welcome to **SchemaCraft AI** — the zero-backend, deterministic relational schema architect and in-memory mock API sandbox, built specifically for the Devpost 'Build With AI: Basics' hackathon."*

---

### Slide 2: Natural Language to 3NF Relational Architecture (0:24 - 0:48)
> **Visual:** Mouse clicks the "B2B SaaS Platform" preset pill. The UI instantly updates within 15 milliseconds, reorganizing the canvas into normalized `organizations`, `roles`, `users`, `subscriptions`, and `audit_logs` cards (`02_domain_presets.png`).
> 
> **Voice-Over (Verbatim):**  
> *"With SchemaCraft, you describe your domain in plain English — or click one of our four instant archetypes: Healthcare Triage, B2B SaaS, E-Commerce, or Ride-Sharing Fleet.*
> 
> *Under the hood, our client-side compiler tokenizes entities and enforces strict Third Normal Form: scalar columns in 1NF, full primary-key dependency in 2NF, and zero transitive dependencies in 3NF — all sorted with a Directed Acyclic Graph to guarantee zero circular foreign key deadlocks."*

---

### Slide 3: Multi-Target Code Generation & 1-Click DX (0:48 - 1:12)
> **Visual:** Switch to the "Prisma Schema" tab, then the "PostgreSQL DDL" tab. Click the "Copy Code" button, showing the green 'Copied!' toast feedback in the bottom-right corner (`03_prisma_and_sql.png`).
> 
> **Voice-Over (Verbatim):**  
> *"SchemaCraft isn't just a diagrammer — it's an actionable code compiler. In one click, you get production-grade PostgreSQL DDL complete with `uuid-ossp`, B-tree indexed foreign keys, and `ON DELETE CASCADE` constraints.*
> 
> *Switch tabs to view valid Prisma 5+ models with reciprocal relational arrays, or export TypeScript interfaces. Every snippet includes a one-click 'Copy Code' button with instant visual feedback and bundle downloads."*

---

### Slide 4: Sub-6ms Edge In-Memory Mock REST Sandbox (1:12 - 1:40)
> **Visual:** Click into the "In-Memory Mock API" tab. Click the "Send Request" button. Watch the live developer metrics bar update: Status: 200 OK, Latency: 4ms, Memory: Local Edge AST. Filter response records using the search bar (`04_mock_api_telemetry.png`).
> 
> **Voice-Over (Verbatim):**  
> *"Here is the game changer: our In-Memory Mock REST Sandbox. You don't need to spin up a mock server, configure Docker containers, or deploy cloud functions.*
> 
> *Frontend engineers can immediately execute simulated REST requests right inside the browser. With realistic relational seed data that respects parent-child UUID integrity, sub-six millisecond response times, and real-time payload filtering, frontend and backend development can proceed in parallel from minute zero."*

---

### Slide 5: Enterprise Open-Source & Hackathon Readiness (1:40 - 2:00)
> **Visual:** Display the comprehensive engineering foundation: Dockerfile, MIT License, architecture diagram, and planning artifacts (`05_hackathon_compliance.png`).
> 
> **Voice-Over (Verbatim):**  
> *"SchemaCraft AI is built for enterprise durability. It features a multi-stage Docker container build, MIT open-source licensing, complete architectural specifications in `scope.md`, `prd.md`, and `spec.md`, and 100% offline-first execution with zero third-party API key dependencies.*
> 
> *Accelerate your MVP velocity with SchemaCraft AI. Thank you!"*
